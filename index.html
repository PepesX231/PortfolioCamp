สมัครเข้าร่วมกิจกรรม

คำถามที่พบบ่อย

ไม่มีพื้นฐาน สมัครได้ไหม?

ได้ เลือก Project Track แล้วเริ่มสร้างเกมจากพื้นฐาน

มีผลงานที่ไม่ใช่เกม สมัครได้ไหม?

ได้ หากมีผลงานที่ต้องการนำไปทำพอร์ต สามารถเลือก Portfolio Track

ยังไม่รู้ว่าจะเข้าคณะไหน สมัครได้ไหม?

ได้ มาค้นหาเส้นทางและถามข้อสงสัยกับรุ่นพี่มหาวิทยาลัย

ต้องเตรียมอะไรบ้าง?

คอมพิวเตอร์หรือโน้ตบุ๊ก อินเทอร์เน็ต และบัญชี Discord หากเลือก Portfolio Track ให้เตรียมไฟล์ผลงานที่มี

ต้องเดินทางไหม?

ไม่ต้อง กิจกรรมจัดออนไลน์ผ่าน Discord และ HamsVillage

จบค่ายแล้วได้อะไร?

Portfolio Track ได้ทำรูปเล่มพอร์ตและคลิปซ้อมสัมภาษณ์ ส่วน Project Track ได้สร้างเกม ทั้งสอง Track มีคลิปนำเสนอผลงาน 2 นาที

เข้าค่ายแล้วสอบติดแน่นอนไหม?

ค่ายช่วยเตรียมผลงานและพอร์ต การรับเข้าศึกษาขึ้นอยู่กับเกณฑ์ของแต่ละมหาวิทยาลัย

Portfolio Track

นำผลงานที่มีมาเขียนพอร์ต ฝึกเล่าเรื่อง และเตรียมตัวสำหรับการสัมภาษณ์

  • เขียน SOPเล่าเหตุผลที่อยากเข้าคณะและเป้าหมายของตัวเอง
  • เขียนบรรยายผลงานอธิบายไอเดีย วิธีทำ และสิ่งที่ได้เรียนรู้
  • จัดรูปเล่มเลือกผลงานและจัดหน้าให้อ่านง่าย
  • ซ้อมสัมภาษณ์อัดคลิปแนะนำตัวและฝึกตอบคำถาม
  • โชว์ผลงานเลือกผลงานเด่นที่สุด 1 ชิ้น พร้อมภาพปกและคลิปนำเสนอ 2 นาที

รูปเล่ม Portfolio คลิปซ้อมสัมภาษณ์ และคลิปนำเสนอผลงาน

Project Track

เริ่มจากพื้นฐาน แล้วสร้างเกมของตัวเองเพื่อใช้ต่อยอดทำพอร์ต

  • Game Designคิดไอเดียและออกแบบวิธีเล่น
  • Game Developmentลงมือสร้างเกมด้วย Unity หรือ Roblox
  • Storytellingเล่าให้คนเข้าใจและเห็นจุดเด่นของเกม
  • โชว์ผลงานทำภาพปกและคลิปนำเสนอเกม 2 นาที

เกม 1 เกม พร้อมคลิปนำเสนอผลงาน
