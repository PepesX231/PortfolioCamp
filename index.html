Portfolio Track

มีผลงานแล้ว แต่ไม่รู้จะเขียนพอร์ตยังไง นำผลงานที่มีมาเรียบเรียง ฝึกเล่าเรื่อง เขียน SOP และจัดรูปเล่ม

  • Storytelling
    เล่าผลงานให้คนอ่านเข้าใจ
  • SOP
    เขียนเหตุผลที่อยากเข้าคณะและมหาวิทยาลัย
  • Portfolio Design
    จัดรูปเล่มและเลือกเนื้อหา
  • Presentation
    ฝึกนำเสนอผลงานเด่น
  • ได้กลับบ้าน
    พอร์ต 1 เล่มพร้อมส่ง

เหมาะกับคนที่มีผลงานอยู่แล้ว โดยเฉพาะคนที่กำลังเตรียมยื่นรอบ Portfolio

Project Track

ยังไม่มีผลงาน มาสร้างชิ้นแรก เริ่มจากออกแบบเกม เรียนพื้นฐาน แล้วลงมือทำเกมของตัวเองในค่าย

  • Game Design
    คิดไอเดียและออกแบบวิธีเล่น
  • Game Development
    เรียนรู้การสร้างเกม
  • Project Building
    ลงมือทำเกมของตัวเอง
  • Presentation
    ฝึกนำเสนอผลงาน
  • ได้กลับบ้าน
    เกม 1 เกมพร้อมเล่น ทำด้วย Roblox หรือ Unity

เหมาะกับคนที่ยังไม่มีผลงาน หรืออยากเริ่มสร้างเกม

สิ่งที่ต้องเตรียม

  • ทุกคน
    คอมหรือโน้ตบุ๊ก และเน็ต
  • ทุกคน
    บัญชี Discordและบัญชี Hamster Hub ตามที่ทีมแจ้ง
  • Portfolio Track
    ไฟล์ผลงานและรูปที่มีถ้ามีคณะเป้าหมาย เตรียมชื่อคณะไว้ด้วย

    ไม่ต้องมีผลงานมาก่อนติดตั้งโปรแกรมตามที่ทีมแจ้ง
